# Reproduction & Execution Guide

## 1. Prerequisites & Environment Setup

### Python Environment
- Python 3.10+
- PyTorch 2.0+
- Dependencies: `numpy`, `pandas`, `scipy`, `scikit-learn`, `matplotlib`, `datasets`

### R Environment
- R version 4.0+
- CRAN Packages: `dagitty`, `sandwich`, `clubSandwich`, `lme4`
- GitHub Packages: `faircause` (`devtools::install_github("dplecko/CFA")`)

---

## 2. Step 1: Model Training Phase (`FairTP/`)

To train all 4 models sequentially on `METR-LA`:

```bash
cd final_package/FairTP
./run_metr_la.bat
```

### Individual Command Execution
```bash
# 1. DCRNN (Diffusion Convolutional Recurrent Neural Network)
python experiments/dcrnn/main_fairS_SD_all.py --dataset METR-LA --max_epochs 100 --device cuda:0

# 2. GWNet (Graph WaveNet)
python experiments/gwnet/main_fairS_SD_all.py --dataset METR-LA --max_epochs 100 --device cuda:0

# 3. DLinear (Decomposed Linear Baseline with RevIN)
python experiments/dlinear/train_dlinear.py --dataset METR-LA --max_epochs 100 --device cuda:0

# 4. Historical Average (True HA Baseline)
python experiments/ha/train_ha.py --dataset METR-LA --device cpu
```

*Note: Change `--device cuda:0` to `--device cpu` if training without a GPU.*

---

## 3. Step 2: Causal Analysis Execution (`07_13_methodology_validation/`)

Navigate to the methodology directory:
```bash
cd final_package/07_13_methodology_validation
```

Run the validation scripts in sequential order:

```bash
# 1. Setup & FairTP Metric Verification
python 07_setup_and_fairtp_verified.py

# 2. Structural DAG Identifiability Check
Rscript 08_dag_identifiability.R

# 3. Counterfactual Fairness Decomposition (Ctf-DE / Ctf-IE / Ctf-SE)
Rscript 09_ctf_estimation_faircause.R

# 4. Statistical Power Simulation (n=207)
Rscript 10_power_simulation.R

# 5. Reliability Weight Sensitivity (PCA vs. Heuristic)
python 11a_reliability_weights.py
Rscript 11b_reliability_sensitivity.R

# 6. Disparity Metric Reconciliation (Persistence vs. Residual)
python 12_disparity_reconciliation.py

# 7. Temporal Panel Alignment & Mixed-Effects Regression
Rscript 13_temporal_alignment.R
```
